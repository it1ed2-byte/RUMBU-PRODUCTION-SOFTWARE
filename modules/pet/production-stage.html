How Stage 8 — Production works
  1. Production starts automatically when the plant manager sends an agent's material here (Stage 7). The start time is stamped for you.
  2. Add a batch each time one is made: the grade (AA or AB), the weight of each bag, and the operator and shift leader IDs (their names appear by themselves). Keep adding batches until the material is finished.
  3. The lab (Stage 9) tests each batch as you add it. When the lab submits a result, review it here: Approve, ask for a retest, or ask for a rerun.
  4. Approving a batch generates its QR labels, which you can print and paste on the bags.
  5. When every batch is approved and the material is finished, press Complete Production. Waste is worked out automatically from Quality Control, and the run goes to the next step.
