User Management

Add, assign roles, and deactivate users for the Government Contracts module.

How to add a new user:
1. Go to Supabase Dashboard → Authentication → Users → Add user and create their account.
2. Copy the UUID Supabase assigns to that user.
3. Paste it in the form below, fill in their name, role, and save.
The user can then log in to the main RumbuApp and will have access to the contract module.
