Only Admins and Super Admins can change store setup. You can view it.

🏢 Branches Served

Everyone in these branches can send requests to this store. A store can serve several branches, and a branch can be served by several stores.

✅ Approvers

Approvers process and release this store's requests. If a store has no approvers, only a Super Admin can process its requests.

👥 Extra Requesters

People outside the linked branches who may also send requests to this store.
